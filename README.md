# IctalTech Site

Site institucional simples da IctalTech.

## Objetivo

Publicar uma presença institucional inicial, leve, segura e de fácil manutenção.

## Estrutura

- `index.html`: página principal
- `assets/style.css`: estilos visuais
- `.gitignore`: arquivos ignorados pelo Git

## Decisão técnica inicial

Este projeto começa como site estático em HTML e CSS puro.

Não há ambiente Python, Node.js ou backend nesta fase, pois não existem dependências, build ou processamento local.

## Segurança e privacidade

Este repositório não deve conter:

- senhas
- tokens
- chaves de API
- arquivos `.env`
- dados de pacientes
- dados sensíveis de pesquisa
- documentos internos estratégicos
